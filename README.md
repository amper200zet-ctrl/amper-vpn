# AMPER VPN — личный портал

Next.js 15 + TypeScript + Supabase. Адаптивный интерфейс в голубом стиле AMPER.

## Уже реализовано в исходниках
- Главная страница с тремя основными действиями.
- Вход/регистрация по email magic link через Supabase Auth.
- Callback обмена кода на сессию.
- Защищённая серверная страница личного кабинета.
- Чтение статуса подписки из PostgreSQL.
- Однократная активация 3-дневного пробного периода через защищённую SQL-функцию.
- Выход из аккаунта.
- Пустые состояния для VPN-конфигурации и истории платежей.

## Пока не подключено
- Telegram Login (нужен username бота, домен и проверка Telegram Login/OIDC).
- Реальный Telegram-бот URL (задать `NEXT_PUBLIC_TELEGRAM_BOT_URL`).
- Платежи и webhook.
- Выдача/отзыв VLESS-конфигураций через VPN-панель.
- Админ-панель и аудит операций.

## Запуск
1. Установить Node.js 20.9+.
2. `npm install`
3. Скопировать `.env.example` в `.env.local` и заполнить URL и anon/publishable key проекта Supabase.
4. В Supabase Auth включить Email OTP / magic link и добавить URL сайта в Redirect URLs, включая `http://localhost:3000/auth/callback`.
5. Выполнить `supabase/schema.sql` в SQL Editor.
6. `npm run dev` и открыть `http://localhost:3000`.
7. Для production: `npm run build`, затем развернуть на Vercel и добавить те же env-переменные.

## Важно
Это полноценная стартовая кодовая база, но не запущенный сервис. Пока Supabase и домен не настроены, регистрация и trial не смогут работать. Перед публичным запуском нужно проверить email delivery, лимиты, RLS, резервные копии, безопасность API и юридические требования. Платежи/инфраструктуру оформлять с участием родителя/законного представителя.
